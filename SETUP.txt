KSIJ Connect - Team Setup

1. Clone the repository into your XAMPP htdocs folder as ksij-connect.
2. Copy config.example.php to config.php and enter the shared remote database
   host, port, name, username, and password provided by Samir.
3. Use the existing shared database. Skip importing database/schema.sql;
   schema.sql is a reference for fresh installations only.
4. Start Apache in XAMPP. Local MySQL is not needed for the remote database.
5. Run: C:\xampp\php\php.exe tools/check_setup.php
6. Open http://localhost/ksij-connect/

Member login: public/login.php
  Use KSIJ001 through KSIJ005. OTP_TEST_MODE shows the generated code for
  development. Codes expire after five minutes and can only be used once.

Volunteer / CC login: public/team_login.php
  volunteer1, volunteer2, volunteer3, ccmember1, ccmember2 / test123
  volunteer4 is intentionally inactive and cannot log in.

Admin login: public/staff_login.php
  admin1 / test123. Keep this URL out of public navigation.

Starting files:
  Samir: public/member_chat.php
  Hasan: public/admin/index.php
  Qamar: public/staff_dashboard.php
  Asad: tools/test_auth.cjs

Shared APIs:
  includes/auth_member.php: requireMember()
  includes/auth_staff.php: requireRole('admin') or
                         requireRole(['volunteer', 'cc_member'])
  includes/db.php: getDb() and $pdo
  includes/bootstrap.php: appUrl(), csrfField(), checkCsrf()
  includes/notifications.php: createNotification(), getUnreadNotifications(),
                             markNotificationRead()

The workspaces are starter pages. Chatbot and business workflows still need
implementation. OTP_TEST_MODE is for development; disable it and configure
PHP email delivery before using real member accounts.

Browser tests (requires Node.js and Playwright):
  Install Playwright separately: npm install --prefix tmp/qa playwright
  Install Chromium: node tmp/qa/node_modules/playwright/cli.js install chromium
  PowerShell:
    $env:PLAYWRIGHT_MODULE = "$PWD/tmp/qa/node_modules/playwright"
    node tools/test_auth.cjs
  Tests use fictional seed accounts and consume OTPs for KSIJ001.
  Screenshots are saved in tmp/auth-qa.

config.php, docs/, and tmp/ stay local and are ignored by Git.
Share database credentials privately; each teammate keeps their own config.php.
All database changes are shared immediately. Coordinate schema changes with the team.
Use different member accounts when testing OTP login at the same time; requesting
a new code for an account invalidates that account's previous unused codes.
